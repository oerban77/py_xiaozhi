Shorten over-long UI labels so they fit their controls

Several button labels and form labels were wider than their controls and
got clipped, e.g. "Start Conversation" (~160px) inside a button capped at
140px. Shortened the wording while keeping the same meaning, and widened
a few narrow label columns that were still too small for their text.

Buttons: "Start Conversation" -> "Start Chat", "Stop Conversation" ->
"Stop Chat", "Switch to Manual/Auto" -> "Manual/Auto", "Refresh Devices"
-> "Refresh", "Open Activation Page" -> "Open Page", "Save Wake Word" ->
"Save", "Testing..." -> "Testing".
Labels: "Noise Suppression Preprocessing" -> "Noise Suppression",
"Delay Compensation Frames" -> "Delay Frames", "Parallel Music Playback"
-> "Parallel Music", "Vision-Language Model (VL API)" -> "Vision Model
(VL API)", "Wake Word Directory" -> "Wake Word Dir", etc.
Shortcut hints and the Opus sample-rate hint were shortened too.

Button text is display-only (no code compares it), so the shorter labels
are safe.
